# CHG-001 / F1-01 — Tasks

> Scope: static discovery, documentation and testable architecture contracts only. Do not bootstrap Next.js, execute legacy systems, create migrations, access real customer data or deploy anything. Exactly three principal tasks.

- [x] **1. Inventariar el repositorio y las fuentes con evidencia verificable.** Inspeccionar el árbol y la configuración reales en el commit objetivo; documentar `docs/architecture/repository-baseline.md` con rutas y líneas verificables, estado observado, riesgos, ausencia de código si procede y clasificación OBSERVED / APPROVED_DECISION / INFERRED / NEEDS_CONFIRMATION. Registrar fuentes conversacionales no versionadas sin atribuirles evidencia ficticia. **Verificación:** toda afirmación observada es trazable; nada fue ejecutado o modificado fuera de artefactos documentales.

- [x] **2. Definir contratos de arquitectura y ADR de decisiones.** Documentar `docs/architecture/target-architecture.md` y `docs/adr/ADR-0001-modular-monolith.md`: siete módulos, límites por capa, dependencias permitidas, transacción comercial local e idempotencia, conciliación fiscal externa, controles de seguridad, opciones descartadas y exclusiones. **Verificación:** las reglas de negocio objetivo se distinguen claramente del código existente; no se inventan firmas API, entidades físicas ni proveedor e-CF.

- [x] **3. Construir la matriz de trazabilidad y verificar CHG-001.** Crear `docs/qa/traceability.md` vinculando fuente/decisión → módulo/contrato → historia o Change futuro → AC → QA para los siete módulos y flujos críticos; incluir NEEDS_CONFIRMATION donde falte la fuente versionada. Revisar cobertura, inconsistencias y verificar el conjunto OpenSpec con `openspec validate chg-001-architecture-baseline --strict` cuando la CLI esté disponible. **Verificación:** la matriz contiene cobertura del flujo venta-pago-inventario-e-CF-E34-reembolso/devolución, los hallazgos pendientes no figuran como cerrados y se adjunta resultado real de validación; no marcar completado sin evidencia.
